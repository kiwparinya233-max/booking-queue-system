คู่มือการใช้งาน Telegram Bot

1. วิธีการหา Telegram Chat ID ของคุณ

1. ค้นหาบอท @userinfobot ใน Telegram

2. กดปุ่ม Start เพื่อเริ่มใช้งาน

3. นำตัวเลข ID ที่บอทรายงานกลับมาใส่ในช่องกรอกแล้วกดบันทึก

2. เพื่อการรับแจ้งเตือนคิวงานเข้ามาใหม่

1. ค้นหาแชท BookingRmuttTechEducation_bot ใน Telegram

2. กดปุ่ม Start เพื่อเปิดสิทธิ์ให้บอทส่งแจ้งเตือนเมื่อมีคำขอจองคิวส่งถึงคุณได้

ขั้นตอนการขอ Telegram Bot Token

1. เปิดแอปพลิเคชัน Telegram (ใช้ได้ทั้งในมือถือหรือคอมพิวเตอร์)

2. ค้นหาคำว่า @BotFather ในช่องค้นหา และกดเข้าไปที่แชทของบอทตัวนี้ (สังเกตเครื่องหมายติ๊กถูกสีฟ้าว่าใช่บอททางการหรือไม่)

3. กดปุ่ม Start หรือพิมพ์คำสั่ง /start

4. พิมพ์คำสั่ง /newbot แล้วกดส่ง

5. ตั้งชื่อแสดง (Bot Name) ของบอทตามที่ระบบถาม เช่น MyBot

6. ตั้งชื่อ Username (Bot Username) ซึ่งต้องลงท้ายด้วยคำว่า bot ด้วยเสมอ (ตัวอย่าง: my_bot_123_bot)

7. หากตั้งชื่อสำเร็จ @BotFather จะส่งข้อความตอบกลับมา ซึ่งในข้อความนั้นจะมี HTTP API Token (ลักษณะเป็นชุดตัวเลขและตัวอักษรต่อกัน) ให้คัดลอกเก็บไว้ใช้งาน

ข้อควรระวัง!!! ห้ามเผยแพร่ Bot Token นี้ในที่สาธารณะ เพราะผู้อื่นอาจนำ Token ไปใช้ควบคุมบอทหรือส่งข้อความสวมรอยได้ หากทำหลุด สามารถพิมพ์คำสั่ง /revoke ในแชทกับ @BotFather เพื่อยกเลิก Token เก่าและสร้างใหม่ได้ทันที
